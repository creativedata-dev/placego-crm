Configuração da Meta Cloud API

⚠️
Antes de começar
  • O número não pode estar ativo no WhatsApp App ou WhatsApp Business App — a conta precisa ser deletada primeiro
  • Você vai precisar de acesso ao telefone para receber o código de verificação por SMS ou ligação
  • Tempo total estimado: ~45 minutos na primeira vez
01 Criar conta no Meta Business Manager ~5 min
✓

Acesse business.facebook.com e clique em "Criar conta"

🔗 business.facebook.com
✓

Preencha o nome da empresa, seu nome e email comercial

✓

Confirme o email — você receberá um link de verificação

Use um email da empresa, não pessoal. Ele será o administrador principal.
✓

Na primeira tela, ignore a sugestão de criar anúncios — vá direto em Configurações

02 Criar um App no Meta for Developers ~10 min
✓

Acesse developers.facebook.com com a mesma conta Facebook do administrador do Business Manager

🔗 developers.facebook.com/apps
Você precisa estar logado com a conta Facebook pessoal do administrador — não uma conta de empresa.
✓

No canto superior direito, clique em "Meus apps" → "Criar app"

✓

Na pergunta "Para que serve o seu app?", selecione "Outro" → clique em Próximo

A opção "Business" foi renomeada para fluxo diferente em versões recentes do portal. Selecione "Outro" para ter acesso ao produto WhatsApp Business.
✓

Em "Selecionar um tipo de app", escolha "Business" → clique em Próximo

✓

Preencha o nome do app (ex: "PlaceGo CRM" ou o nome da imobiliária) e informe um email de contato

✓

Em "Conta Business", selecione o Business Manager criado no passo 01 — clique em "Criar app"

Se a conta Business não aparecer na lista, significa que o Business Manager ainda não foi verificado ou o usuário não tem acesso de administrador.
✓

Na tela de produtos do app, role até encontrar "WhatsApp" e clique em "Configurar"

✓

Confirme novamente o Business Manager quando solicitado → clique em "Continuar"

Isso vincula o app à conta WABA (WhatsApp Business Account) da empresa e libera o acesso à Cloud API.
03 Adicionar e verificar o número de telefone ~15 min
✓

Dentro do app, vá em WhatsApp → "Configuração da API"

✓

Em "Números de telefone", clique em "Adicionar número de telefone"

O número NÃO pode estar registrado no WhatsApp App ou WhatsApp Business App. Se estiver, você precisa deletar a conta antes.
✓

Preencha: nome de exibição da empresa, categoria (ex: Imóveis), e o número com DDD e DDI (+55)

✓

Escolha a verificação por SMS ou ligação — insira o código recebido

Chips virtuais (Vivo, Claro virtual) funcionam. Evite VOIP — pode não receber o código.
✓

Após verificar, o número aparece na lista com status "Conectado"

04 Copiar o Phone Number ID ~2 min
✓

Ainda em WhatsApp → "Configuração da API", localize a seção "Enviar e receber mensagens"

✓

No campo "De", selecione o número que você acabou de verificar

✓

Abaixo aparece o campo "ID do número de telefone" — copie esse valor (são ~15 dígitos)

Exemplo: 123456789012345 — este é o valor que vai no campo Phone Number ID do PlaceGo CRM.
05 Criar um System User e gerar o Access Token permanente ~10 min
✓

Volte ao Business Manager → menu lateral → "Usuários do sistema"

🔗 Abrir Usuários do sistema
Não use o token temporário da tela de API Setup — ele expira em 24h e quebrará o CRM.
✓

Clique em "Adicionar" → dê um nome (ex: PlaceGo CRM Bot) → perfil: "Administrador" → Criar usuário do sistema

✓

Com o usuário criado, clique em "Gerar novo token"

✓

Selecione o App criado no passo 02

✓

Marque as permissões: whatsapp_business_messaging e whatsapp_business_management → clique em "Gerar token"

Marque "Token nunca expira" se disponível — caso contrário, anote a data e renove antes do vencimento.
✓

Copie o token gerado (começa com EAA...) — ele não será exibido novamente

Salve o token em local seguro imediatamente. Ao fechar a janela, ele some.
06 Conceder acesso ao App para o System User ~5 min
✓

Ainda nos Usuários do sistema, selecione o usuário criado → clique em "Conceder acesso a recursos"

✓

Selecione "Apps" → escolha o app do passo 02 → marque todas as permissões → Salvar

✓

Depois vá em "Apps" no menu lateral → selecione o seu app → Adicionar pessoas → adicione o System User como administrador

07 Configurar no PlaceGo CRM ~2 min
✓

Nesta página, selecione "Meta Cloud API" no seletor de provedor acima

✓

Cole o Phone Number ID (passo 04) no campo correspondente

✓

Cole o Access Token (passo 05) no campo correspondente

✓

Clique em "Salvar configuração" — o sistema valida as credenciais automaticamente

✓

Pronto! Os corretores desta empresa passarão a receber notificações de novos leads pela API oficial do Meta

Limites de envio da Meta Cloud API

Os limites sobem automaticamente conforme o uso — sem necessidade de solicitação manual. Para notificações de corretores, o Tier 1 (1.000/dia) é suficiente para a grande maioria dos cenários.

❓

Dúvidas frequentes

Posso usar o número atual do WhatsApp Business?

Não diretamente. Você precisa primeiro remover a conta do WhatsApp Business App: Configurações → Conta → Excluir minha conta. Só então o número fica disponível para a API oficial.

O número precisa ter chip físico?

Não. Chips virtuais (e-SIM, Vivo Easy Virtual, etc.) funcionam para receber o SMS de verificação. Após verificado, o chip não precisa mais estar ativo — o número fica na nuvem do Meta.

Quanto custa?

A Meta cobra por conversa (janela de 24h). As primeiras 1.000 conversas de negócio por mês são gratuitas. Acima disso, o preço varia por país (Brasil: aprox. USD 0,075–0,125/conversa).

O token expira?

Tokens de System User podem ser gerados sem expiração. Tokens de usuário comum expiram em 60 dias. Use sempre System User Token para integrações de produção.

O que acontece se o token for revogado?

As notificações param de ser enviadas silenciosamente (o CRM registra o erro nos logs). Basta gerar um novo token e atualizar na página de configuração.

Precisa de conta de anúncios para criar o app?

Não. A conta de anúncios (Facebook Ads) serve apenas para campanhas pagas. A Cloud API do WhatsApp é gerenciada pelo Business Manager — a imobiliária pode não ter nenhum anúncio ativo e ainda assim usar a API.

Com qual conta Facebook devo acessar o developers.facebook.com?

Com a conta pessoal do Facebook do administrador do Business Manager. Não existe "conta Facebook de empresa" — o portal de desenvolvedores usa sua conta pessoal, mas tudo fica vinculado ao Business Manager da empresa.
